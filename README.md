## `> FEATURED_PROJECTS`

### 01 — StockFlow

**Order & Inventory Management Platform**

A backend-focused application for managing products, inventory, and order workflows, with a React-based user interface.

- Designed around inventory consistency and reliable order processing.
- Implements atomic stock updates to prevent overselling under concurrent orders.
- Includes order lifecycle handling, safe retries, and inventory reservation and release workflows.
- Explores authentication, authorization, and security controls for a practical business application.

**Stack:** Java 21 · Spring Boot · PostgreSQL · React

[**→ Explore StockFlow**](https://github.com/bossshhh/stockflow)

### 02 — Semantic Segmentation of Road Scenes

**Deep Learning & Computer Vision**

A PyTorch project that performs pixel-level classification of urban road scenes using the Cityscapes dataset.

- Implemented a semantic segmentation pipeline covering data preparation, preprocessing, training, and evaluation.
- Compared FCN-ResNet50 as a baseline against DeepLabV3-ResNet50.
- Worked with pixel-wise annotation masks and 19 remapped training classes.
- Explored computer vision techniques relevant to intelligent transportation and autonomous driving.

**Stack:** Python · PyTorch · CNNs · Cityscapes · Kaggle

[**→ Explore the project**](https://github.com/bossshhh/Semantic-Segmentation-of-road-scenes)

### 03 — Kindred

**Voice-First AI Companion for Older Adults**

A capstone MVP exploring a calm conversational companion designed to help older adults interact with technology and stay connected to their personal context.

- Built a FastAPI backend and React + Vite frontend.
- Supports conversational interactions, stored profiles, and persistent conversation history.
- Includes a safety-oriented routing approach for handling sensitive questions and emergency scenarios.
- Supports offline demo mode and optional live language-model responses through Groq.

**Stack:** Python · FastAPI · React · Vite · SQLite · Groq

*Prototype only — not a medical device or diagnostic system.*

[**→ Explore Kindred**](https://github.com/bossshhh/Kindered)
